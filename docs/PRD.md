# PRD：China Mainland Movie Calendar

## 目标

提供一个可长期订阅的中国大陆院线上映日历。国产片与进口片使用同一口径；影片定档后自动出现，提档或延期后保持同一个日程并更新日期。

## 目标用户

- 使用 Apple Calendar、LunarBar、Google Calendar 或 Outlook 的中国大陆电影观众。
- 希望一次订阅、无需逐条手工录入的用户。

## 核心场景

1. 用户通过固定 URL 订阅日历。
2. GitHub Actions 每日读取中国大陆“即将上映”片单。
3. 新定档影片以全天日程加入。
4. 同一影片改档时依靠稳定 UID 更新原日程，不产生重复。
5. 影片连续三次从来源消失且原日期尚未来临时，保留日程并标记“已撤档，待定”。

## V1 范围

- 中国大陆院线公映日期。
- 国产片和进口片。
- 仅收录已明确到具体日期的影片；只有月份或年份的预告不猜测日期。
- RFC 5545 ICS、静态订阅页、GitHub Actions 每日更新。
- 数据来源适配器、持久状态、变更历史、基础测试。

## 非目标

- 具体影院、城市或场次。
- 流媒体上线日期。
- 购票、评分、推荐或票房。
- 保证片方永不临时改档。

## 验收标准

- ICS 可被 Apple Calendar 导入或订阅。
- 每部影片 UID 由来源 ID 稳定生成。
- 日期变化不会创建第二条影片日程。
- 连续三次缺失前不误判撤档。
- 生成的 ICS 每行符合 75 字节折行限制。
- 解析、状态合并、ICS 和页面测试全部通过。
- GitHub Actions 可手动运行并在内容变化时提交生成物。
- GitHub Pages 提供固定 HTTPS 与 `webcal` 订阅地址。

## 约束与风险

- 当前数据入口是豆瓣电影公开的“即将上映”网页，并非正式 API；页面结构或访问策略变化会导致更新失败。
- GitHub Actions 网络出口可能偶发触发站点限流，抓取器必须有限重试并在异常时停止写入，不能发布空日历。
- 事实性档期仍可能晚于片方公告，用户应以片方或购票平台为准。
